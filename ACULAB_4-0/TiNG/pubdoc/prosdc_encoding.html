Prosody data communications Encodings

Prosody defines an encoding as the way data is formatted for transport on a timeslot. The method of transport is called a protocol. Protocols are described in Prosody data communications Protocols.

The encodings available are:

  • HDLC - frames of data with optional CRC
  • sync - raw uninterpreted data
  • async - characters with start bit, data, stop bit
  • none - protocol dependent data

The possible combinations of protocols and encodings are described in Prosody data communications Protocols and Encodings.
