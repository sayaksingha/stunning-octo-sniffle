Prosody

Prosody uses a variety of Aculab cards to provide many computer telephony functions. There are three main types of documentation available:

  • Guides which explain how to use the features
  • Reference manuals which provide a comprehensive description of every API function
  • Application notes which give extra information on individual areas of functionality
