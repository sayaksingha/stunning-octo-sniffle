Prosody installation guide: test program timeslots

The test programs must be told which timeslots to use. These must be switched (using the Aculab switch driver) to the desired destination. See Appendix A of the switch driver API guide for full details of the timeslot numbering for each supported card type.

To perform loopback testing, use the 'switch' program in the $(TiNG)/diag directory to connect the output to the input. For example, on a ProsodyX card you would switch 64:0 to 64:0. To connect an external call, for example on timeslot 32:1, connect it both ways, e.g. 64:0 to 32:1 and 32:1 to 64:0. Test programs such as ansrec handle this connection automatically. They only need to be told which timeslot to use. For example, on a ProsodyX card you could specify that 64:0 is to be used and it would make the connections to the incoming call.
