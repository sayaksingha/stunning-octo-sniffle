Prosody TiNG

The documentation for Prosody TiNG is in the pubdoc directory.

The directories are:

NameContains
VisualStudio Files to support projects in Microsoft VisualStudio
adsilib An application library for supporting ADSI
apilib The main API library
call A place to pre-build call-control libraries so that many test programs can use them without building them for every program
diag Various diagnostic programs and other tools.
doc The driver/API interface automatically generated from the documentation of the internals of TiNG.
gen Global auto-generated files
highapi The high-level API libraries
hsif Header files for the interface between firmware, driver, and API library.
include Fully expanded include files
lib Fully expanded source code, DLLs etc.
libutil Utility code used when building many parts of TiNG
notes Odd notes on the internals etc. that do not need to be distributed to customers
odpr A place to pre-build ODPR libraries so that many test programs can use them without building them for every program
pubdoc The public documentation.
switch A place to pre-build switch libraries so that many test programs can use them without building them for every program
test Various test/demo programs.
