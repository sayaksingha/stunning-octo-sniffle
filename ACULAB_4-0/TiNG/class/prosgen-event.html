Event creation

The C API function smd_ev_create() does not follow the usual convention of taking a parameter structure. Consequently, the C++ version also does not follow the same convention as the other C++ functions. Instead, the create() method is overloaded as follows:

Error create(int type, tSMChannelId chan)
Create a standard channel-specific event. Equivalent to calling smd_ev_create() with kSMChannelSpecificEvent for the eventChannelBinding parameter.
Error createnonidle(int type, tSMChannelId chan)
Create a non-idle channel-specific event. Equivalent to calling smd_ev_create() with kSMChannelSpecificEventNonIdle for the eventChannelBinding parameter.
Error create(int type)
Create an any-channel event. Equivalent to calling smd_ev_create() with kSMAnyChannelEvent for the eventChannelBinding parameter.

These methods are part of Prosody with classes.
