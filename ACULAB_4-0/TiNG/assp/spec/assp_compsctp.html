SCTP Packet contents and their relevance to ASSP

Here's a list of SCTP packet fields with considerations of how necessary they are in ASSP.

Common header contents

source port
Something similar is required. See discussion of addressibility.
dest port
Something similar is required. See discussion of addressibility.
Verification tag
Not needed. Packets can be protected by sequence number range checking.
checksum
Something similar is required.

DATA chunk

U bit
Not required. Unsequenced delivery is not supported.
B bit
Not required. ASSP is a stream protocol, so it does not have record boundaries in the data.
E bit
Not required. ASSP is a stream protocol, so it does not have record boundaries in the data.
TSN
Something similar is required.
Stream identifier S
Not required. ASSP does not aggregate multiple sub-streams within a stream.
Stream sequence number n
Not required. ASSP does not aggregate multiple sub-streams within a stream.
Payload protocol identifier
Not required. ASSP does not aggregate multiple sub-sub-streams within a sub-stream.

INIT chunk

Initiate tag
Not required. Used only to provide the verification tag in subsequent packets..
Advertised Receiver Window Credit
Not required as a separate option as normal flow control mechanisms can be used.
Number of outbound streams
Not required. ASSP does not aggregate multiple sub-streams within a stream.
Number of inbound streams
Not required. ASSP does not aggregate multiple sub-streams within a stream.
Initial TSN
Something similar is required. We can use the ACK field in the reverse direction.
IPv4 address
Not required. ASSP does not support multiple addresses per connection.
IPv6 address
Not required. ASSP does not support multiple addresses per connection.
Cookie preservative
Possibly permit as an option. Note that the longer a cookie's lifetime the less it protects the server sending it.
Host name address
Not required. ASSP does not support multiple addresses per connection.
Supported address types
Not required. ASSP does not support multiple addresses per connection.

INIT ACK chunk

See the INIT chunk for most values.

State cookie
An equivalent is required.
Unrecognised paramter
Not required. All errors are reported by RST.

SACK chunk

Cumulative TSN ACK
An equivalent is required.
Advertised Receiver Window Credit
An equivalent is required.
Gap ack blocks
An equivalent is required.
Duplicate TSN
Not required.

HEARTBEAT chunk

Not required. (Functionality can be achieved by sending any FASTACK packet).

HEARTBEAT ACK chunk

Not required. (Functionality can be achieved by sending any FASTACK packet).

ABORT chunk

Equivalent required.

SHUTDOWN chunk

Equivalent required.

SHUTDOWN ACK chunk

Not required. A single acknowledgement mechanism covers both data and shutdown.

ERROR chunk

Not required. Errors are all fatal.

COOKIE ECHO chunk

Equivalent required.

COOKIE ACK chunk

Equivalent required.

SHUTDOWN COMPLETE chunk

Not required. A single acknowledgement mechanism covers both data and shutdown.

ECNE chunk

An equivalent option may be provided.

CWR chunk

An equivalent option may be provided.
